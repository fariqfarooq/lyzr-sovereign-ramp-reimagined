# Visual asset slots

The page is intentionally complete with DOM/CSS product visuals, so it does not ship with copied marketing imagery.

If you have approved Lyzr assets, these are the three useful replacements:

- `optimus.webp` — transparent or clean-background hardware render
- `control-plane.webp` — product UI screenshot for the hero/stack
- `customer-proof.webp` — optional enterprise/case-study image

Use `next/image`, keep explicit dimensions, and prefer AVIF/WebP exports.
